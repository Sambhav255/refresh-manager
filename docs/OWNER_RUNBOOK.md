# Refresh Manager — owner runbook

Short guide for installing, updating, and recovering your data without IT help.

## First install

1. Run the Windows installer you received from your supplier.
2. On first launch, complete setup: owner password, first staff PIN, and **pick a backup folder** (USB drive or folder on this PC).
3. Keep that USB plugged in or use a folder that is backed up to the cloud.

## Daily routine

- Let the app run its **automatic backup** at the scheduled time (Settings → Backup settings).
- Use **Save a copy now** before big changes or if the dashboard says backup is stale.
- Finish **End of Day** and have staff log out before updates or restores.

## Check for updates

1. Owner login → **Settings** → **About & updates**.
2. Click **Check for updates**. If an update is available, download then install.
3. Or use **Install from file** with the Windows .exe installer your supplier sent.
4. Always log out staff first; the screen will remind you.

## Restore from a backup

1. Owner login → **Settings** → **Backup settings** → **Restore from a copy**.
2. Pick a recent refresh_backup file from your backup folder.
3. Enter your owner password (and backup passphrase if you use encryption).
4. The app restarts with the restored data. **Everything entered after that backup date is lost.**

## Get help

- **Export support logs** (Backup settings) and send the text file to support.
- Note your version from **About & updates** (version and build id).
