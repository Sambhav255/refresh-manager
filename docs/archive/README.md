# Archive

Historical planning/audit documents from the "harden-money-path" phase (early July 2026 —
the P0–P3 money-path hardening work: the sale-model migration, transaction_lines/
transaction_payments, the security fixes documented in `ABOUT.md` §7). All of it shipped
and is already summarized, with reasoning, in [`ABOUT.md`](../../ABOUT.md) at the repo root.

Kept for the historical record and for anyone who wants the original blow-by-blow, not
because anything in here still describes open work. If you're picking up this codebase,
start at [`docs/HANDOFF.md`](../HANDOFF.md), not here.
